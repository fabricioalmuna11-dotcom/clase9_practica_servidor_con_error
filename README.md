# Curso Full Stack - Clase 9
### Sprint 3 - Ejercicio de Práctica
Este repositorio contiene un Proyecto con un frontend básico y un servidor API de Mascotas. Sin embargo, el servidor presenta errores que impiden su correcto funcionamiento.

Te invitamos a clonar el repositorio, identificar y corregir los errores para que la API cumpla con su funcionalidad original.

¡Mucho Éxitos!

<br/>

### Pasos para clonar el repo:

1. Dentro del Repo, desplegamos el botón que dice <span style="background-color: #3f993fff; padding: 3px 4px; border-radius: 4px;"><> Code</span>
2. Copiamos la url HTTPS.
3. En tu PC, parados en la carpeta donde queres que se descargue el proyecto, abrimos terminal y haces:

` git clone https://github.com/PiaAchigarITBA/clase9_practica_servidor_con_error.git `

4. Accede a las carpeta correspondiente:

 ⚠️ Usamos el comando `cd` para acceder a las carpetas. Primero al "proyecto" y luego a "server_con_errores"
<br/>

 ` cd clase9_practica_servidor_con_error ` 
<br/>
 ` cd server_con_errores `
<br/>

5. npm install
6. npm run dev
7. Lee el error en la consola y a corregir!!
<br/>
<br/>

## Consigna
En clase vamos a compartir que decia el error, porque pasaba y como lo arreglaron.
<br/>

### Qué significa "terminado":

- El servidor levanta sin errores en consola.
- Los endpoints documentados en /info responden correctamente (probalos con Thunder Client/Postman/curl, no solo mirando el código).
- El frontend (frontend/index.html) puede listar, crear, editar y borrar mascotas sin errores en la consola del navegador.
<br>
Tip: cada vez que arreglen algo y el error cambie, es una buena señal ... van bien :muscle:
No se olviden de ir documentando el error, que pasó y como lo solucionaron.
